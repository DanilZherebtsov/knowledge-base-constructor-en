# Constructor mechanics catalog

The registry of detachable mechanics. The constructor reads it to know which mechanics exist, what each one touches, and what it depends on. A preset manifest (`presets/<class>.md`) lists the chosen mechanics in its `mechanics:` field; the assembler ([ASSEMBLY.md](ASSEMBLY.md)) executes each one's `mechanics/<name>/_about.md`.

## Composition rules

- **Central-type exclusivity.** `claim-graph` (type `claims/`), `spec-lifecycle` (type `architecture/`), and `decision-lifecycle` (type `entities/`) each claim their own central type. A project has one central type — these three are mutually exclusive as the "core" (overlays on top are fine). `software-engineering` doesn't occupy a central type (an overlay) — compatible with any class lifecycle.
- **Code is one competence mechanic.** All work on code (writing, ownership, deploys) lives in `software-engineering`: it is an overlay, doesn't occupy the central type, and **composes** with any lifecycle. In saas it pairs with `spec-lifecycle` (the spec = the unit of work, `software-engineering` = the execution). There is no exclusivity between the code mechanic and the class lifecycle — they are different axes (what we track vs how we write code).
- **Optional dependencies.** A dependency may be soft (a mechanic works without an optional co-mechanic). The assembler wires a dependency in only if it's listed in the preset's `mechanics` (or is mandatory, like `claim-graph` for `question-lifecycle`).
- **Deactivation.** An optional mechanic NOT in the preset's `mechanics` is simply not placed into the project. The base skeleton is **not** uprooted: base machinery (including **roles** — `roles.md`, `roles/_template.md`, the "Roles" section) is always present and cannot be switched off (ADR-0027; the former "deactivate roles" branch was removed together with that mechanic).
- **Lift, not fork.** A generic improvement discovered while extracting a mechanic from a class is lifted into base/the mechanic, not left as a copy in the class (legacy of ADR-0013).
